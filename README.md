# Data-Analysis-Dashboard-Ecxel-project

⚙️ Tools & Technologies

Python

Pandas (for data manipulation)

OpenPyXL (for Excel automation)

Matplotlib / Seaborn / Power BI / Streamlit (for visualization — include whichever you used)

Excel (.xlsx)

🚀 Features

Automated reading and updating of hotel records from Excel files

Calculates key metrics like total revenue, occupancy rate, and average booking duration

Generates visual charts for better insights

Exports cleaned and analyzed data back to Excel

User-friendly and easily customizable

📈 Results

Reduced manual data entry time by 80%

Provided visual insights into hotel performance metrics

Helped identify peak booking periods and occupancy trends
